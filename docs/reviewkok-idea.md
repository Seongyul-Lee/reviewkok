# 리뷰콕 (ReviewKok)

> Jev 기반 소상공인 리뷰 자동 관제 서비스, 창업 아이디어 문서

## 1. 한 줄 소개

흩어진 가게 리뷰를 AI가 실시간으로 읽고 "지금 꼭 봐야 할 리뷰"만 골라 알려주며, 답글 초안까지 써주는 소상공인용 리뷰 관리 서비스.

## 2. 문제 정의

- 소상공인은 배달앱, 지도 앱, SNS 등 여러 채널에 리뷰가 흩어져 있어 매일 모든 리뷰를 확인하기 어렵다.
- 리뷰 하나하나에 답글을 다는 데 시간이 많이 들고, 장사가 바쁜 시간대에는 사실상 불가능하다.
- 위생·이물질·배송 사고 같은 심각한 불만이 다른 리뷰에 묻혀 늦게 발견되면 별점 하락과 고객 이탈로 이어진다.
- 반복되는 불만(예: "양이 줄었다", "배달이 늦다")을 데이터로 정리해 볼 방법이 없어 개선 포인트를 감으로만 판단한다.

## 3. 해결 방안

리뷰콕은 두 종류의 AI를 역할에 맞게 나눠 쓴다.

### [1단계] Jev: 빠르고 저렴한 대량 판단

모든 리뷰를 수집 즉시 Jev에 넣어 아래 항목을 판정한다.

- 감정: 긍정 / 중립 / 부정
- 불만 유형: 맛, 양, 위생, 배송, 응대, 가격, 기타 (복수 선택)
- 긴급도 점수: 0~1 (위생·이물질·건강 관련은 높게)
- 답글 필요 여부: 예 / 아니오
- 각 판단의 신뢰도 점수

### [2단계] LLM: 필요한 리뷰에만 문장 생성

Jev가 "답글 필요"로 판정한 리뷰에 한해서만 LLM이 사장님 말투에 맞춘 답글 초안을 작성한다. 사장님은 확인 후 수정·게시만 하면 된다.

### [3단계] 사람 확인 장치

Jev의 신뢰도가 낮은 리뷰는 자동 분류를 확정하지 않고 "확인 필요" 목록으로 보내 사장님이 직접 판단하게 한다.

## 4. 왜 Jev인가 (기술 선택 근거)

- Jev는 문장을 생성하지 않고 선택지·점수·예/아니오 같은 정해진 형태의 결과만 돌려주는 "System One" 모델이다. 리뷰 분류처럼 답의 형태가 정해진 작업에 정확히 맞는다.
- 출력값이 미리 정한 타입으로 제한되므로, 앱에서 결과를 바로 로직에 연결할 수 있고 엉뚱한 답이 나올 여지가 적다.
- 선택·점수 판단에는 신뢰도(0~1)가, 예/아니오 판단에는 확률이 함께 나와 "자동 처리할 것"과 "사람이 볼 것"을 나누는 기준으로 쓸 수 있다.
- 회사 발표 기준으로 분류 작업에서 일반 LLM보다 훨씬 빠르고 저렴하다. 리뷰 수천 건을 매일 처리해도 원가 부담이 작아 저가 구독 모델이 가능해진다. (수치는 제조사 주장이며, 독립 분석에서는 속도 중앙값 7배, 비용 중앙값 30배)
- 모든 리뷰를 LLM으로 처리하는 경쟁 방식 대비, 비싼 LLM 호출을 "답글이 필요한 리뷰"로만 줄여 운영비를 낮춘다.

> [!NOTE]
> **한계 인지**
>
> - Jev는 텍스트 입력만 받으므로 사진 리뷰는 텍스트 부분만 분석한다.
> - 주 학습 언어가 영어라 한국어 정확도는 영어보다 조금 낮다(공개 벤치마크 기준).
> - 2026년 9월 공개된 얼리 액세스 모델이라 가격·정책 변동 가능성이 있다. 필요하면 다른 분류 모델로 바꿀 수 있게 대비한다.

## 5. 타깃 고객


| 구분    | 대상                         | 특징                                                    |
| ----- | -------------------------- | ----------------------------------------------------- |
| 1차 타깃 | 방문 손님 비중이 높은 1\~3개 매장 운영 소상공인 | 네이버 플레이스 리뷰는 많은데 관리 인력이 없는 층. 배달 매장은 배달앱과 공식 연동이 생기면 확장 |
| 2차 타깃 | 프랜차이즈 가맹점주 / 소규모 프랜차이즈 본사  | 여러 매장의 리뷰를 한 화면에서 비교·관리하려는 수요                         |
| 3차 타깃 | 대학가 상권 (초기 테스트 시장)         | 학생 고객 비중이 높아 리뷰 작성이 활발하고, 접근성이 좋아 현장 인터뷰와 파일럿 모집이 쉽다. |


## 6. 주요 기능

1. **통합 리뷰 피드** — 네이버 플레이스 공식 제휴로 받은 리뷰(이후 배달앱 등 제휴 채널 추가)를 한 화면에 모아 긴급도 순으로 정렬
2. **긴급 알림** — 긴급도 높은 리뷰가 들어오면 카카오 알림톡으로 즉시 전송
3. **답글 초안 자동 생성** — 사장님이 고른 말투(정중함/친근함)로 초안 작성, 원클릭 수정
4. **주간 리포트** — 불만 유형별 건수 추이, 개선된 항목/악화된 항목 요약
5. **확인 필요함** — AI가 확신하지 못한 리뷰만 따로 모아 사람 판단 유도

## 7. 사용자 시나리오

금요일 저녁 7시, 대학가에서 홀 영업 위주의 치킨집을 하는 사장 김씨는 주문 처리로 정신이 없다.

- **7:12** 새 리뷰 3건 수집 → Jev가 1초 안에 전부 분류
- **7:12** "치킨에서 머리카락이 나왔어요" 리뷰가 긴급도 0.94로 판정되어 김씨 휴대폰에 알림 도착
- **7:15** 김씨가 알림을 열자 사과 답글 초안이 준비되어 있음 → 수정 후 게시
- 나머지 리뷰는 그날 쌓인 것과 함께 마감 후 한 번에 확인
- 월요일 아침 주간 리포트: "대기 시간 불만 3주 연속 증가" 확인 → 피크 시간 홀 인력 추가 검토

## 8. 경쟁 및 차별점

- **기존 방식**: 사장님이 직접 확인 / 대행 업체에 위탁 / LLM 기반 답글 자동화 도구
- **리뷰콕의 차별점**
  - (a) 답글 자동화보다 리뷰를 중요도로 분류하고 우선순위를 매겨 "놓치면 안 되는 리뷰를 먼저 잡는 것"에 집중
  - (b) 공식 연동만 사용해 플랫폼 약관 위반이나 계정 위탁 위험이 없음
  - (c) 신뢰도 기반으로 AI 판단과 사람 판단을 나누어 오작동 위험 관리
  - (d) 단발성 답글이 아닌 불만 유형 데이터 축적으로 가게 개선까지 연결

## 10. 마케팅 전략

1. **대학가 상권 파일럿** — 학교 주변 음식점 10곳에 3개월 무료 제공, 사용 전후 답글률·별점 변화를 사례로 만든다.
2. **성과 수치 중심 메시지** — "하루 리뷰 확인 시간 30분 → 5분" 같은 실측 사례를 홍보 문구로 활용 (파일럿에서 실제로 측정한 값만 사용)
3. **소상공인 커뮤니티 공략** — 자영업자 온라인 카페·단톡방에 파일럿 사례 공유와 무료 요금제 안내
4. **공식 연동 파트너·POS 업체와 제휴** — 데이터 연동 파트너를 판매 채널로도 삼는다. 이미 소상공인과 접점이 있는 업체의 부가 서비스로 입점 (선례: 페이히어 POS의 네이버 플레이스 리뷰 연동)

## 11. 리스크와 대응


| 리스크                      | 대응                                                     |
| ------------------------ | ------------------------------------------------------ |
| 리뷰 수집의 법적·정책 문제          | 네이버 플레이스와 공식 제휴를 맺고 시작한다(선례: 페이히어 POS 연동). 배달앱은 별도 약정을 맺은 뒤 추가. 크롤링과 사장님 계정 위탁은 쓰지 않음 |
| 네이버 제휴가 늦어지거나 성사되지 않음 | 제휴 체결을 사업의 첫 관문으로 둔다. 이미 네이버와 연동한 POS 업체를 통한 경로도 검토 |
| 네이버가 AI 답글·부정 리뷰 알림을 자체 제공 | 중요도 분류·우선순위, 확인 필요 목록, 주간 불만 리포트로 차별화하고, 네이버 기능을 보완하는 제휴 서비스로 제안 |
| Jev 한국어 정확도가 영어보다 낮음      | 신뢰도가 낮은 판단은 사람 확인으로 넘기고, 필요하면 다른 분류 모델로 교체 |
| 신생 모델 의존 리스크 (가격·서비스 변동) | 분류 모듈을 인터페이스로 분리해 모델 교체 비용 최소화                         |
| AI 오분류로 중요한 리뷰를 놓칠 위험    | 신뢰도 낮은 건은 반드시 사람 확인 목록으로 보내는 안전장치                      |
| AI 답글의 진정성 논란            | 자동 게시 없이 사장님 확인 후 게시하는 방식 유지                           |


## 12. 기대 효과

- **사장님**: 리뷰 관리 시간 절감, 심각한 불만 조기 대응, 별점 관리
- **고객**: 빠르고 성의 있는 답변, 불만 사항의 실제 개선
- **상권**: 리뷰 데이터 기반으로 가게 운영 품질 전반 향상
- **기술적 의의**: "판단은 빠른 모델, 문장은 생성 모델"로 역할을 나눈 비용 효율적 AI 설계 사례
