### 매장 1곳의 월 원가 계산

**가정**
- 월 리뷰 N = 100 / 300 / 1,000건
- 답글 필요 비율 30%, 긴급 알림 비율 5%
- 분류 호출: 입력 600토큰, 출력 30토큰
- 답글 호출: 입력 700토큰, 출력 400토큰
- 알림톡: 건당 14.3원(솔라피 13원 + VAT)
- 환율: 1달러 = 1,338.92원(2026-10-07) [36]
- Jev 분류 단가는 건당 약 0.034원(600토큰 × 0.042달러/100만 토큰)이다.

**두 방식**
- A안(리뷰콕) = Jev 분류 + LLM 답글(답글 필요분) + 알림톡
- B안 = LLM 분류 + LLM 답글(답글 필요분) + 알림톡

| 답글·분류 LLM | N=100 (A / B) | N=300 (A / B) | N=1,000 (A / B) | N=1,000에서 월 9,900원 대비 (A / B) |
|---|---|---|---|---|
| gpt-6-luna | 86 / 92원 | 257 / 277원 | 857 / 924원 | 8.7% / 9.3% |
| Gemini 3.5 Flash-Lite | 123 / 154원 | 370 / 463원 | 1,235 / 1,542원 | 12.5% / 15.6% |
| Claude Haiku 4.5 | 183 / 280원 | 550 / 841원 | 1,833 / 2,804원 | 18.5% / 28.3% |
| Claude Sonnet 5.5 | 292 / 489원 | 875 / 1,468원 | 2,918 / 4,892원 | 29.5% / 49.4% |

- 알림톡 비용은 모델과 관계없이 N=100/300/1,000에서 72/215/715원이다.
- PG 수수료와 인프라 비용은 포함하지 않았다.
